## Data Source: scalr_container_image

Retrieves information about a container image that can be used as a runner image. Requires the `container-images:read` permission on the account.

## Example Usage

```terraform
data "scalr_container_image" "example1" {
  id = "cimg-xxxxxxxxxx"
}

data "scalr_container_image" "example2" {
  name       = "scalr/runner"
  visibility = "system"
}
```

## Schema

### Optional

- `id` (String) The identifier of the container image, in the format `cimg-<RANDOM STRING>`.
- `name` (String) The container image repository name without a tag, for example `scalr/runner`.
- `visibility` (String) The image visibility: `system` for a Scalr-managed image or `public` for a custom image registered in the account.

### Read-Only

- `description` (String) The image description.
- `latest_version_id` (String) The identifier of the latest version of the image.
- `registry_url` (String) The OCI registry URL the image is pulled from.
- `repository` (String) The repository path within the registry.
- `sync_status` (String) The tag synchronization state of the image: `pending`, `synced`, `failed` or `no_versions`.
