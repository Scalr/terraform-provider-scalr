## Data Source: scalr_container_image_version

Retrieves information about a version of a container image.

## Example Usage

```terraform
data "scalr_container_image" "runner" {
  name       = "scalr/runner"
  visibility = "system"
}

# The latest version of the image
data "scalr_container_image_version" "latest" {
  container_image_id = data.scalr_container_image.runner.id
}

# A specific version of the image
data "scalr_container_image_version" "pinned" {
  container_image_id = data.scalr_container_image.runner.id
  version            = "0.5.0"
}
```

## Schema

### Required

- `container_image_id` (String) The identifier of the container image. Use the `scalr_container_image` data source to look it up.

### Optional

- `version` (String) The image tag, for example `0.4.0`. If omitted, the latest version of the image is returned.

### Read-Only

- `available` (Boolean) Whether the version can be selected and used. Always `true` for system image versions.
- `compressed_size` (Number) The compressed linux/amd64 manifest size in bytes, including config and layers.
- `created_at` (String) The time when the version was registered.
- `id` (String) The identifier of the container image version, in the format `cimgv-<RANDOM STRING>`.
- `latest` (Boolean) Whether this is the latest version of the container image.
