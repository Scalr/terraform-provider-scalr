## Resource: scalr_module_namespace_environment

Gives a single environment access to the modules of a module namespace.

Each link is a separate resource, so an environment can be attached to a shared namespace from the configuration that creates the environment. Creating or destroying a link leaves the other links of the namespace untouched.

-> **Note** Manage a namespace's environments either with these resources or with the `environments` attribute of the [`scalr_module_namespace`](module_namespace) resource, not both. Omit `environments` there to leave the links to this resource.

The namespace must not be shared: a shared namespace is available in every environment already.

## Example Usage

```terraform
resource "scalr_environment" "example" {
  name       = "my-environment"
  account_id = "acc-xxxxxxxxxx"
}

# Give the new environment access to an existing module namespace.
resource "scalr_module_namespace_environment" "example" {
  module_namespace_id = "modns-xxxxxxxxxx"
  environment_id      = scalr_environment.example.id
}
```
