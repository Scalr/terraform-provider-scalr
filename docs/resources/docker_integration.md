## Resource: scalr_docker_integration

Manages the state of Docker (OCI) registry integrations in Scalr. The integration is used to publish OCI-sourced modules, see `scalr_module`.

## Example Usage

```terraform
resource "scalr_docker_integration" "example" {
  name               = "ghcr"
  registry_url       = "https://ghcr.io"
  username           = "my-user"
  password           = var.ghcr_token
  export_credentials = true
}
```

## Schema

### Required

- `name` (String) Name of the Docker integration.
- `password` (String, Sensitive) The registry password or personal access token.
- `registry_url` (String) The registry URL, e.g. `https://ghcr.io`. Only one integration per registry host is allowed. Redirecting URLs are rejected.
- `username` (String) The registry username.

### Optional

- `export_credentials` (Boolean) Whether to injects the credentials into plan and apply runs for direct oci:// module access. Default `false`.

### Read-Only

- `id` (String) The ID of this resource.
- `status` (String) Status of the integration after the latest connection test.
