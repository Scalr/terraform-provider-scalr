## Resource: scalr_module_test_configuration

Manages the tofu test configuration of a module in Scalr.

## Example Usage

```terraform
resource "scalr_module_test_configuration" "example" {
  module_id                      = scalr_module.example.id
  enabled                        = true
  failure_behavior               = "notify"
  trigger_on_pr_activity_enabled = true
  trigger_on_new_version_enabled = true
}
```

## Schema

### Required

- `module_id` (String) ID of the module, in the format `mod-<RANDOM STRING>`.

### Optional

- `enabled` (Boolean) Indicates whether the test configuration is enabled. Default: `true`.
- `failure_behavior` (String) The behavior to apply when a test run fails. Valid values are `failure` and `notify`. Default: `notify`.
- `trigger_on_new_version_enabled` (Boolean) Indicates whether a test run should be triggered when a new module version is synced. Default: `false`.
- `trigger_on_pr_activity_enabled` (Boolean) Indicates whether a test run should be triggered on pull request activity. Default: `false`.

### Read-Only

- `id` (String) The ID of this resource.
