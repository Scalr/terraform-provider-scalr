## Resource: scalr_splunk_integration

Manages the state of Splunk integrations in Scalr. The integration sends Scalr audit logs and run events to a Splunk HTTP Event Collector (HEC).

## Example Usage

```terraform
resource "scalr_splunk_integration" "example" {
  name     = "splunk"
  endpoint = "https://http-inputs-acme.splunkcloud.com"
  token    = var.splunk_hec_token
  index    = "scalr_audit"
}

# Self-managed Splunk Enterprise, events go to the default index of the HEC token
resource "scalr_splunk_integration" "enterprise" {
  name     = "splunk-enterprise"
  endpoint = "https://splunk.example.com:8088"
  token    = var.splunk_enterprise_hec_token
}
```

## Schema

### Required

- `endpoint` (String) Base HTTP Event Collector URL. Must use https and must not include `/services/collector`.
- `name` (String) Name of the Splunk integration.
- `token` (String, Sensitive) HEC token. Indexer acknowledgment must be turned off for it.

### Optional

- `index` (String) Splunk index for the events. If not set, events go to the default index of the HEC token.

### Read-Only

- `account_id` (String) ID of the account the integration belongs to.
- `err_message` (String) Error message reported by Scalr when the integration is in the `failed` status.
- `id` (String) The ID of this resource.
- `status` (String) Status of the integration: `active`, `disabled` or `failed`. Scalr sets the `failed` status when Splunk rejects the token or the index during delivery.
